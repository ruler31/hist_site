# 🌍 History of Everything

> An interactive educational website for exploring world history, countries, historical events, object evolution, and numismatics.

## 📚 Project Overview

**History of Everything** is a digital platform designed to help students and history enthusiasts learn history in an engaging, structured, and visual way. The content is divided into four major categories:

- **Object Evolution** – how everyday and technological items have changed over time  
- **Historical Events** – major turning points in world history  
- **History of Countries** – key stages in the development of civilizations and nations  
- **Numismatics** – rare coins and the history of currency systems  

The platform features timelines, image galleries, filtering tools, and a responsive design with support for both Russian and English languages.

## 🎯 Project Goals

- Develop a user-friendly and responsive website  
- Integrate interactive learning tools and historical data  
- Centralize fragmented historical content into a unified source  
- Provide quick and categorized access to verified historical facts  

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **Database:** SQLite  
- **Development Tools:** PyCharm, Visual Studio Code  
- **Deployment:** Render.com  

## 🔐 Features

- User registration and login system  
- Favorite and history tracking for logged-in users  
- Interactive timelines with visual animations  
- Language support (Russian / English)  
- Filterable and searchable content

# 🌍 History of Everything

> Интерактивный сайт для изучения истории стран, предметов, событий и нумизматики.

## 📚 Описание проекта

**“History of Everything”** — это образовательный веб-ресурс, предназначенный для школьников, студентов и всех, кто интересуется историей. Сайт структурирует историческую информацию по четырём основным направлениям:

- **Эволюция предметов** — как развивались бытовые и технические объекты;
- **Исторические события** — важные даты и поворотные моменты мировой истории;
- **История стран** — от древних цивилизаций до современности;
- **Нумизматика** — редкие монеты и история денежных систем.

Платформа предлагает временные линии, визуализации, галереи и адаптивный интерфейс с удобным поиском и навигацией.

## 🎯 Цели проекта

- Создание удобного, современного, адаптивного сайта.
- Повышение интереса к изучению истории.
- Объединение информации из разных исторических областей в одном месте.

## 🛠️ Используемые технологии

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **База данных:** SQLite  
- **IDE:** PyCharm, Visual Studio Code  
- **Деплой:** Render.com  

## 🔐 Функционал

- Авторизация и регистрация пользователей
- Сохранение избранных тем
- Хронологические ленты событий
- Поддержка двух языков (RU/EN)
- Интерактивные элементы: временные шкалы, галереи, презентации
